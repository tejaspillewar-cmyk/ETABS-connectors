================================================================================
                    ETABS LIVE CONNECTOR - SETUP INSTRUCTIONS
================================================================================

This folder contains the ETABS Live Connector tool. It has been designed to be 
fully portable, meaning you can place this folder anywhere on your computer. 
You do NOT need administrator privileges to set it up or run it.

Please follow these steps carefully to install and use the tool.

--------------------------------------------------------------------------------
STEP 1: INSTALL PYTHON (If you don't already have it)
--------------------------------------------------------------------------------
1. Go to https://www.python.org/downloads/
2. Click the "Download Python" button.
3. Run the downloaded installer.
4. ***CRITICAL STEP***: At the very bottom of the first installation screen, 
   make sure you check the box that says "Add Python to PATH".
5. Click "Install Now" (or "Install for this user only" if you don't have 
   admin rights).

--------------------------------------------------------------------------------
STEP 2: RUN THE AUTOMATED SETUP SCRIPT
--------------------------------------------------------------------------------
You only need to do this step ONCE on your computer.

1. Open the "ETABS Connector" folder that contains these instructions.
2. Find the file named "setup.bat".
3. Double-click "setup.bat" to run it.
4. A black command window will open. It will automatically create a local 
   environment and download the necessary background files (pandas, openpyxl, etc).
5. Wait for it to say "Setup complete!". Press any key to close the window.

--------------------------------------------------------------------------------
STEP 3: REGISTER THE PLUGIN IN ETABS
--------------------------------------------------------------------------------
You only need to do this step ONCE. ETABS will remember it forever.

1. Open ETABS.
2. Go to Tools > Add/Show Plugins > Add.
3. Browse to the "PyLauncherPlugin" folder inside "ETABS Connector" and select
   PyLauncherPlugin.dll.
4. Click Add.

This has to be done through ETABS's own dialog -- an earlier version of this
tool tried to script this step by editing ETABS.ini directly, but ETABS
regenerates that file on its own and silently drops entries that were not
added through "Add/Show Plugins", so the shortcut kept disappearing. Adding it
through the dialog is what makes it stick.

--------------------------------------------------------------------------------
STEP 4: USING THE TOOL
--------------------------------------------------------------------------------
Whenever you want to use the tool:

1. Open your model in ETABS.
2. Go to "Tools" in the top menu.
3. You will see "Live Connector" (or whatever you named it in Step 3) at the 
   bottom of the Tools menu. Click it!
4. The control panel GUI will launch and automatically connect to your open 
   ETABS model.

================================================================================
TROUBLESHOOTING
================================================================================
- If you run setup.bat and it says "Python is not installed", please repeat 
  Step 1 and ensure you check the "Add Python to PATH" box.
- If you move the "ETABS Connector" folder to a different location on your PC
  later, remove the old entry in Tools > Add/Show Plugins and re-add it by
  browsing to PyLauncherPlugin.dll at its new location.
- If you see an error message pop up in ETABS when you click "Live Connector"
  saying it could not find etabs_gui.pyw, it means the PyLauncherPlugin folder
  was moved out from beside etabs_gui.pyw -- keep them in the same "ETABS
  Connector" folder (PyLauncherPlugin looks one directory up for the script).
